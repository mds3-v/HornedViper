API 接口

HornedViper 的 JSON API；任务控制与审批。

接口列表

方法路径说明
GET/api/health健康检查
GET/api/tasks任务列表
POST/api/tasks创建任务，JSON：title / mode / goal
GET/api/tasks/{id}任务详情、意图、执行、事件、待审批
POST/api/tasks/{id}/pause暂停任务
POST/api/tasks/{id}/resume继续任务
POST/api/tasks/{id}/stop停止任务
POST/api/tasks/{id}/approvals/{approvalID}审批意图，JSON：decision / reason
